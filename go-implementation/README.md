# Go Implementation

This is a small Go implementation of the same Martian Robots challenge.

I completed the .NET version as the main submission and then reimplemented the problem in Go for fun, keeping the design deliberately simple and idiomatic to Go rather than copying the .NET structure.

## Requirements

- Go 1.27+

Check your installed version with:

```bash
go version
```

Run the tests

From the go-implementation folder:

```bash
go test ./...
```
Format the code
```bash
gofmt -w .
```



Run

```bash
go run .
```


Run with Test data
```bash
go run . testdata.txt
```
